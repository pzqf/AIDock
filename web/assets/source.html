外部生成器
离线暂存交换

              
锁定启用的完整技能包和生成器依赖，准备独立暂存，检查返回镜像。当前支持 Claude Code 与 Codex 的完整技能包；程序执行仍待隔离验收。

              
              
              

              
支持的接入范围
适配文件声明 schema_version、id、declared_version、protocol、runtime_root、entry_relative、tools、network 和 child_processes。协议为 aidock-skill-mirror-v1，network 与 child_processes 均为 deny；tools 选择 claude-code / codex-cli。
runtime_root 是独立依赖目录；全部文件与空目录一起锁定。当前不接收自由命令、环境、MCP 字段或外部桥接源。正文、附件和脚本按完整技能包保留。

不启动外部程序，不安装到工具目录，不修改项目、副本或共同基线。中断后可从历史查看并清理暂存。

清理生成器暂存
确认前后内容变化、未知顶层文件、意外链接或恢复标记不一致都会阻断。清理失败可重新查看并重试。
暂存历史、校验记录与字节快照保留；项目、生成目标和共同基线不在清理范围。

检查当前系统能否保护生成器的输入、输出及运行边界。运行验证使用专用临时夹具，逐项展示实际结果。

            仅协议标记的专用测试资源
清理未完成的隔离测试
将清理以下测试目录及对应临时 AppContainer profile。清理前获取同目录锁并核对恢复标记；仍有运行中的验证、标记不一致、额外顶层内容或意外链接都会阻断。
项目、生成目标、共同基线、技能草稿和检查历史不在清理范围。未识别目录保留，不能自动接管。

            专用测试夹具 · OS 能力原型
验证当前系统的执行隔离
在当前 Local 根创建独立输入、输出和测试哨兵，运行当前版本内置的固定测试程序。Windows 测试进程启动前设置 AppContainer、目录 ACL、无网络能力、禁止子进程及 Job 清理。
验证包含正文、二进制附件、空目录、越界读写、junction、直接 TCP/UDP 和超时清理。所有测试目录与临时 profile 在结束后清理，结果保存在本机。
只使用专用夹具；不运行你登记的生成器、技能或 AI 工具。超时与不明确的网络结果显示证据不足，不会开放外部执行或正式发布。
