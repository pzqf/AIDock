## 证据约束

逐技能文件检查核对稳定 ID、原生名称、修订、所有权及完整文件/目录/模式摘要。一个技能的人工漂移不影响另一技能的文件结论；相同未归属字节不构成安装证明。隔离发现逐技能采用原检查结果，不借用工具整体通过。实际会话与能力目前保持 UNKNOWN。

记录还必须匹配当前项目、作用域、副本和源根，包身份/名称/修订必须相同。来源刷新、保存、工具事务或检查失败立即清除列表的旧结论；读取后端判定过期的记录，只显示历史原因。旧格式记录仍可校验读取，缺失的逐技能字段保持未验证；不会从整体 L1/L3/L4 猜测。原有安装、回退、外部执行和发布门槛不变。
