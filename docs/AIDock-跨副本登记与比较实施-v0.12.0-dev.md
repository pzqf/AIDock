# 跨副本登记与比较实施 v0.12.0-dev

日期：2026-10-14。对应阶段 1D 的登记、共同基线和三方比较子集，阶段 1D 尚未完成。

## 已交付

- 项目/作用域绑定下显式登记最多 32 个副本，稳定 UUID、绝对 `.aidock` 根、分支观察和本机排除策略仅保存在 Local Root。预览、确认、过期检查和失败恢复共用持久事务。
- 任意登记副本可作源，显式选择目标。完整包字节、二进制、空目录、语义元数据、启停与退役记录参与比较。同名但不同 ID 不自动合并。
- 两端已经一致、尚无该条目基线时，可预览并确认共同基线；既有基线不会自动推进。保护基线的完整包字节，缺备份拒绝比较。
- 区分一致、缺共同基线、仅源变化、仅目标变化、双方冲突、源退役、本机排除、外部生成待接入。目标丢失或分支不一致可见，不隐藏失败副本。
- CLI `replica list/register/compare/baseline-plan/confirm/recover`、认证 API、跨副本页面共用后端。读取副本不创建目标锁文件，前后快照变化拒绝观察结果。
- `scripts/start-replica-demo.ps1` 建立专用五副本样例，包含完整包附件、冲突、停用和排除。重复启动保留现有数据；无完成标记的目录拒绝覆盖。脚本使用 UTF-8 BOM，兼容 Windows PowerShell 5 的中文读取。

## 验证

本地 Windows 全仓 race、vet 通过；CLI、API、五副本三方比较、逆向源选择、过期确认、错误摘要、重复登记、缺目标、基线备份损坏和失败恢复测试通过。浏览器专用五副本显示完整包变化与启停冲突，重复登记被拒绝；前端状态回归覆盖取消、过期响应、切换选择和全局库隐藏入口。

只读观察/共同基线确认不会改写被观察的 `.aidock` 项目内容，目标侧锁文件负向测试通过。所有开发测试使用临时目录及本仓库 `.artifacts`，未扫描、修改或测试 `E:\work`、`E:\work2–5`。

## 未开放的范围

此版本不发布共享源、不调用外部生成器、不同步原生工具生成物。逐项选边、暂存生成、整批跨项目提交与恢复、跨副本回退继续实现。当前分支只是本地 `.git/HEAD` 观察；完整 Git/SVN 仓库身份、链接 worktree、跨 scope 与外部生成能力尚未完成。登记身份来自用户明确选择，不按目录相似度推定。

工具安装的 v0.11 能力独立保留；本页比较、源保存或 L1/L2 PASS 都不代表实际会话加载及模型能力生效。
