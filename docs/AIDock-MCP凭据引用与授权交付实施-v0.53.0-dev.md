## 使用与配置

MCP 定义页增加“密钥环境变量”，每行填写一个变量名与完整占位符，例如 OPENAI_API_KEY=${SECRET:openai_key}。名称必须先在该服务器的 secrets 声明，并与 plugin.yaml 的 secrets 集合一致。保存预览列出密钥名称、旧映射和新映射；不接受明文、拼接、默认值或递归展开。重复变量在发请求前拒绝，无效草稿在重绘、关闭和重新打开弹窗时保留。清空映射会移除 env 字段。

mcp.yaml 为每个服务器增加可选 env 对象，最多 64 项。变量使用大写字母开头的字母、数字和下划线，最长 64 字符；PATH、SystemRoot、COMSPEC、临时/用户根、NODE/PYTHON/LD/DYLD 等系统、加载与 AIDock 控制变量明确拒绝。这里的禁止列表不是完整运行时安全沙箱；未来每种启动器还必须提供自己固定的基础环境及运行时变量策略。内部交付仅返回列出的变量，不调用 os.Environ，也不自动设置基础运行环境。

保持 schema_version: 1，旧配置省略 env 仍可读取。这是可选字段扩展；旧版二进制会将新字段判为未知，不能混用旧版编辑包含 env 的文件。冻结设计文件保持原样，当前实现契约及兼容边界记录在本实施文档中。

MCP 检查只读取系统库的名称和修订元数据，显示映射缺少的具体名称、系统库不可用、审计异常或待恢复。名称存在只证明本次观察，不能证明已交付或插件已运行。未映射的声明不自动读取，也不自动交付。

## 授权与回退

项目授权候选增加按实际映射去重、排序的 secrets 名称，完整 env 字节也受原有配置/安装锁摘要约束。普通文件、网络和子进程权限确认不足以交付密钥；有映射时，CLI/API 必须另传 confirm_secrets: true，界面独立列出名称并勾选。业务数据仍限 Public / 未知外部客户端；这一确认只允许将指定凭据交给指定 MCP，绝不允许通过工具结果读取或回传凭据。

改变映射使锁、安装审查和原授权失效；源回退恢复原字节后重新核对当前依赖。撤销无需密钥确认；恢复已撤销的密钥授权必须再次确认名称、用途及权限，并产生新授权记录。重读遇到审查摘要变化或切换候选会清空两项确认；断线失败也保留最后已审查摘要，重连后不能沿用旧范围的确认；成功保存也会清空用途与确认。MCP 和授权输入解析拒绝重复键、大小写别名、null 和未知顶层字段，不回显异常字段值；HTTP 只接受 JSON，CLI 文件可用单文档 JSON/YAML。

源时间线可回退映射、撤销回退；OS 密钥轮换或删除的旧值继续不进入源快照。不能通过源回退找回或回写旧凭据。

## 内部交付与审计

WithMCPEnvironment 仅作为未来受管启动器的内部依赖，不存在读取明文的 CLI/API。先核对实际有效启用、stdio、产物清单、当前安装、项目/作用域/副本/源目录和完整配置绑定，再持有当前授权锁进入 OS 库。受管操作的锁顺序为源 → Profile 层 → 产物 → 授权 → 凭据；撤销、轮换或恢复无法与交付并发成功，锁忙时可以直接拒绝。锁不能阻止不遵守协议的外部编辑者，因此不能声称任意 OS 写入者之间的原子快照。

所有请求名称读取及校验成功后，先为每个唯一名称追加、刷盘 inject / AUTHORIZED 审计，再调用短期内存交付闭包。审计记录当前随机修订及绑定、授权、输入的元数据摘要，无值、值长度或值摘要。AUTHORIZED 只表示允许交付，不证明闭包已调用、进程已启动或消费成功；后续追加失败、上下文取消或闭包失败都可能只有保守的授权记录。部分写入继续按审计损坏阻断，不能作为待 OS 写入意图被 reconcile 重放。

任何密钥缺失、未结意图、审计异常、授权过期或容量不足均不调用交付闭包。成功与失败均清理临时字节缓冲及环境切片，闭包返回错误和 panic 统一遮蔽，避免异常文本回显值；Go 字符串与接收者复制仍不承诺物理擦除。该闭包只允许短期启动交付，不得保留值、记录值或重入这些存储。

## 验收

证据位于 .artifacts/experience-credential-injection-v053/。七个相关包完整无缓存竞态 173 PASS / 0 SKIP / 0 FAIL；源 MCP 定向竞态 84 PASS / 1 SKIP / 0 FAIL，跳过的是仅供子进程调用的 TestMCPArtifactExitHelper。详见 verification.json 和 final-all-*.jsonl。25 组前端回归、13 项 CLI/API 验收通过。Windows 专用测试使用随机临时数据根的真实 OS 凭据，验证只读请求名称、缺失阻断、跨副本拒绝、轮换新修订、撤销、错误遮蔽和磁盘无值；fake backend 另覆盖审计异常、未结意图、取消、重复变量、保留缓冲清理和交付期间轮换。

内置浏览器完成重复变量拒绝、重绘保留、前后对照、实际保存、源回退/撤销及恢复原字节，核对独立密钥确认门槛、授权保存后清空与桌面无横向溢出。发现并修复确认框被通用网格样式居中换行的问题。第一轮最终测试暴露 YAML 测例和“锁忙可直接拒绝”的断言问题，修正后完整相关回归重跑；保留原失败日志。
