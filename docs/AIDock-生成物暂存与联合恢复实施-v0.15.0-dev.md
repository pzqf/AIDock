## 本次交付

跨副本逐项决策后，可明确选择 Claude Code、Codex CLI 或两者。内置 `aidock-owned-mirror-v1` 编译器从每个目标自己的完整候选源生成该目标的全部已启用 owned 技能包。保留目标的条目仍按该目标候选生成；整个目标没有采用源时，本次不为它生成输出。全跳过/全保留仍返回无源变化，纯生成物修复尚未接入此流程。

暂存不把候选写进已登记项目，也不运行工具、技能脚本或外部生成器。复用原生预览编译器，保留原生 frontmatter、二进制、附件、目录、完整版本和目标手写文件。已归属包在替换/移除前检查完整字节、目录和模式，未归属同名占用与人工漂移阻断联合预演。停用或退役只移除此前明确归属的生成包，源完整包与历史仍可恢复。

持久生成清单保存在 Local，绑定源候选计划和摘要、每项决策、各目标源的前后摘要与变化、精确适配器契约、固定输出根、完整前后输出树、包身份/版本/文件摘要、检查原因和变化清单。输出根只由允许的工具目录推导，API 不能提供命令或任意输出路径。暂存末尾和预演确认时再次观察源、注册/分支/基线与生成目录；任一变化拒绝旧计划。预览和取消不创建目标侧锁、工具目录或预演事务。

版本 3 预演将生成清单完整嵌入记录，与目标技能源、工具生成根、共同基线共用逐根绑定的 `Coordinator` 事务。共同加锁、写前备份、持久准备记录、逐目录恢复标记、提交和故障恢复沿用 v0.14 底座。32 副本数量限制保留，独立根上限增至 97：每副本一个源、两个显式工具根，加一个控制基线。没有扩大到共同父目录的写权限。

回退、撤销和中断恢复一起处理源、生成物与预演基线。受影响路径的外部改动阻断恢复，无关新增项保留。恢复依赖嵌入的清单及 Local 完整备份，原始项目失联、独立生成预览文件被移除时，已有预演历史仍可读和重开。版本 1/2 记录保持原有摘要与事务读取方式；没有迁移旧备份。

界面增加可选工具复选框、联合确认、源改动与工具改动清单、生成阻断提示，以及每个副本的计划包数量、文件/目录数量和折叠的版本/目录映射。事务数量分别显示目标副本和生成目录，恢复目录使用副本/工具名称。生成清单是该次计划的记录，当前状态以应用、回退或撤销结果为准。

## CLI / API

沿用 `replica resolve` 产生的候选计划。所有命令使用同一显式 `--managed-root --home --project --scope` 绑定：

```text
replica generation stage --plan <候选 UUID> --digest <候选摘要> --tools claude-code,codex-cli
replica generation show --plan <生成 UUID> --digest <生成摘要>
replica rehearsal run-generated --plan <生成 UUID> --digest <生成摘要>
replica rehearsal history
replica rehearsal show --session <预演 UUID>
```

联合预演的回退/撤销/恢复继续使用 `replica rehearsal plan/apply/recover`。原 `replica rehearsal run` 保留只处理源和基线的兼容行为。

```text
POST /api/replica/generation          {"plan_id":"...","digest":"...","tools":["claude-code","codex-cli"]}
POST /api/replica/generation/show     {"plan_id":"...","digest":"..."}
POST /api/replica/rehearsal/generated {"plan_id":"...","digest":"..."}
```

以上 API 沿用本机 Host/Origin/会话/CSRF 检查，严格拒绝未知字段。生成有阻断项仍保存可审阅清单，确认按钮关闭，后端也拒绝开始联合事务。
