## 本次行为

继承关联可显式保留多个已采纳的完整版本。更新继承版本会保留此前明确采纳的版本，不依据缓存目录或当前全局库自动认领新版本。共享层与本机层各自选择精确 pin；未指定的层继续按原合并规则继承。最终启用项的预检、依赖/兼容检查、导出、工具生成、历史重建与逐技能证据使用同一份最终完整包。

例如共享选择 B、本机选择 A：共享编辑器仍显示 B，本机最终工具包和文件/发现证据使用 A。清除本机覆盖返回共享版本。元数据、完整包、目录与原生名称均按既有规则验证；未采纳的全局最新版本不会自动成为可用包。同名冲突和依赖阻断保留，包内脚本不执行。
