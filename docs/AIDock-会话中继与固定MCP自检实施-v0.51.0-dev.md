# 会话中继与固定 MCP 自检

版本：v0.51.0-dev。实现冻结设计 §9.2 的协议中继基础，并在 CLI/API/管理界面开放固定夹具自检。尚未把实际项目插件连接到中继，阶段 1 与完整 Goal 保持未完成。

## 使用

MCP 定义窗口展开“会话中继自检”，点击“检查会话中继”，核对范围后确认。取消不启动测试；完成后展示通过数量和可展开明细。现有定义草稿和保存预览保持，不自动保存或应用定义。

CLI：`aidock mcp relay-check --probe --json`。省略 `--probe` 只返回 NOT_RUN，不创建数据根或启动进程。

API：POST /api/mcp/relay/check，只接受明确的 probe 布尔字段。会话、来源与 CSRF 验证沿用控制台保护；重复字段、大小写变体、任意命令和目录参数均拒绝。

## 协议范围

- 以换行分隔的 JSON-RPC 2.0 对象，严格检查大小、深度、重复键、方法与请求身份；不同方向使用独立请求身份，中继映射后恢复原客户端字符串或整数 ID。
- 初始化只声明已实现的 tools 能力，不转发客户端采样能力、服务端私有指令、roots、提示词、资源或日志。支持固定协议版本集合，不借初始化声称实际项目生效。
- 工具清单按可信策略里的完整声明摘要核对，服务端 readOnlyHint 不授予权限。分页由中继内部收集、限制数量并去重，不把服务端游标交给客户端。清单变更会使已有列表和在途结果失效。
- 只转发可信策略明确分类且已发现的读取调用；写工具、未知工具、无批准渠道返回 AUTHORIZATION_REQUIRED。调用参数和返回结果必须通过启动方提供的范围/数据策略；缺少任一策略或审计回调即拒绝建立会话。
- 每次转发与交付前重新复核授权。撤销后的结果不交付；上游原始异常正文和数据不直接回显。未知服务端请求无法要求模型采样、根目录或其它上下文。
- 请求数、分页、帧大小、请求及管道写入均有限制。处理取消和迟到响应；客户端 EOF、取消、超时、协议错误及上游退出关闭管道。进程和 broker 的实际生命周期由调用方负责。
- 事件只含动作、固定结果码和内容摘要，不含请求参数、客户端原始 ID、工具结果正文或密钥。当前自检事件随报告返回，尚未连接真实项目持久审计。

## 固定夹具证据

自检只拉起当前 AIDock 自带的固定协议 Helper，接受 normal/crash/hang 三种固定模式，无任意可执行文件、环境、项目路径或插件参数，不进行文件或网络访问。没有全局 daemon 或监听端口。

13 项实际进程检查包含初始化、可信清单、限定 Public 读取、未授权写调用、未知工具、其它项目、其它副本、Internal 结果过滤、未转发调用计数、客户端 EOF、崩溃、超时和取消后的退出等待。服务器计数独立证明被拒绝的请求没有到达它。

证据目录：.artifacts/experience-mcp-relay-v051/。相关 mcprelay/cli/console 三包关闭缓存竞态日志、最终定向回归、24 组前端回归、CLI 报告、两个独立项目原始目录清单及内置浏览器记录均保留。浏览器验收了取消、实际运行、13 项通过以及定义草稿/保存预览保留；最终桌面截图为 relay-desktop.png。本轮未验收窄屏或 Linux 运行。
