# AIDock 控制台连接与草稿保护实施

版本：v0.38.0-dev，2026-10-16。软件版本独立于冻结设计 v0.24；阶段 1 和整个 Goal 继续进行。

## 用户流程

控制台服务断开时，主页面和已打开的弹窗显示中文提示，暂停按钮操作和后续 API 请求。输入框仍可编辑、选择与复制，当前标签页草稿保留。提示固定在弹窗顶部，编辑到下方也可看到。

点击“检查连接”只读取 /api/session，验证当前服务会话并刷新 CSRF；成功后恢复操作。浏览器已终止的 SSE 会重新建立，仍在重连或正常打开的连接保留。自动重连也使用同样会话核对。不会刷新页面或自动重放写请求；断开前正在保存的结果须先重读核对，旧计划仍由服务端重新验证。

会话过期时提示重新运行原启动命令，在新标签页打开新链接，并从旧页面复制草稿。没有自动重启服务或转移旧会话。只有实际 input/pointerdown/keydown 交互才可能每分钟最多读取一次会话，没有后台保活计时器。服务端 15 分钟空闲、6 小时会话上限和 5 分钟启动 token 期限不变。原有源/本机/原生恢复门槛保留；主动关闭控制台不误报断线。

## 验收与证据

真实 console handler 外的传输故障夹具位于 .artifacts/experience-console-connection-v038/browser-fixture.go。复用仓库内独立项目，控制 API 503、401 和 SSE 中断；没有修改产品认证/超时，也不触碰五个真实工作目录。夹具的 SSE 由测试控制，因此不证明实际服务重启后仍能复用旧会话。

内置浏览器通过：正常编辑、弹窗内断线提示、保存按钮禁用、离线重试仍阻断、恢复后同一草稿仍在、终止 SSE 后手动重连并检测第二次断线、401 明确过期提示。390×844 页面宽/滚动宽 390/390，弹窗 331/331，提示 290/290；提示完整可见。控制台未捕获脚本 warn/error；故意注入的 503/401/SSE 失败不当作无网络故障证据。截图：offline-draft.png、recovered-draft.png、expired-draft.png、expired-narrow.png。

HTTP 日志只记录方法/路径；唯一 POST 是会话建立，未发送业务写请求。13 个源文件和 16 个产物文件逐一摘要不变。夹具正常停止；没有创建原生目录、安装登记或正式 SBOM。此前 v0.37 桌面截图已在成功页面重新保存。

18 组前端状态回归、58 项 Demo、19 个 JS 语法检查通过。console/cli 两包聚焦竞态 61 PASS / 0 FAIL；本增量只改前端和版本常量，未重跑全仓竞态，v0.37 全仓 746 PASS / 7 SKIP 结果单独保留。vet、Windows 构建和 Linux 交叉构建通过，Linux 未运行。最终检查汇总见 verification.json。
