# AIDock 内置浏览器验收

日期：2026-10-13。版本：v0.1.0-dev。浏览器：Codex In-app Browser。对象：Go 二进制提供的真实回环只读控制台，不是旧 Demo 或 DOM 替身。

## 结果

17 项界面检查通过。默认宽屏、900×900 和 390×844 的页面均无整页横向溢出；表格与详情保留各自滚动。页面 console error 记录为空。三次控制台均由界面按钮关闭，进程退出码均为 0；验收结束已恢复默认浏览器尺寸。

| 检查范围 | 实际证据 |
| --- | --- |
| 会话建立与刷新 | 一次性 token 建立会话后从 URL 移除；刷新页面后仍能盘点工作区 5 个候选 |
| 副本与作用域 | 工作区 work5 为 1 个；服务端全部 359 个、work5 为 71 个；客户端全部 285 个、work2 为 57 个 |
| 搜索与来源 | 搜索能筛出单个技能；无匹配时显示空态；镜像未包含时生成来源无可见行 |
| 完整技能包 | `designer-doc-gen` 原源展示 3 个文件，附件可展开查看原始摘要；L1–L4 保持未验证，不以有限静态通过替代工具生效 |
| 警告与失败 | 未声明项目引用显示具体路径；显式镜像扫描的缺文件/缺目录能显示具体原因 |
| 项目切换与刷新 | 切换清空旧详情；连续切换后最终清单和当前作用域一致；刷新不保留旧选中包 |
| 键盘 | 从搜索框按 Tab 可进入来源选择框 |
| 响应式 | 1218px 默认宽屏、900px 中等宽度、390px 窄屏均可操作；窄屏关闭入口实际可退出 |
| 退出 | 关闭按钮显示明确提示；CLI 测试进程退出，没有测试服务残留 |

17 个具体检查项和 DOM 观察值保存在本机 [browser-evidence.json](../.artifacts/browser-evidence.json)。此记录是交互验收证据，不是自动化测试脚本。

## 本轮修复

1. 窄屏样式把侧栏 footer 一并隐藏，导致没有可见的“关闭控制台”入口。调整为保留版本与关闭按钮，窄屏实测退出通过。
2. 翻看附件后重新选择技能，详情容器保留旧滚动位置，技能标题可能被裁掉。详情重新渲染时回到顶部；复验 `scrollTop` 从约 90px 恢复为 0，标题位于面板可视区内。

修复后重新编译 Windows 和 Linux/amd64 二进制；前端语法检查、5 项状态回归通过。控制台 race 测试通过。此前完整 Go 回归的 56 PASS、1 SKIP、0 FAIL 仍见开发进度；本轮没有新增写入功能。

## 额外配置发现

仅对 **work5 / 服务端** 显式包含清单中的镜像：总计 153 个候选，其中原源 71、声明镜像 82；143 静态 PASS、4 WARN、6 FAIL。失败包为 `designer-doc-gen`、`development-workflow`、`go-conventions`、`planning-with-files`、`project-lessons`、`verification-before-completion`，均在 `.claude/skills` 的声明镜像中。

`designer-doc-gen` 镜像仅有 `SKILL.md`，正文引用的 `screenshot-subagent-prompt.md` 触发 `REFERENCE_MISSING_OR_UNSAFE`；同名原源包展示了 3 个文件。这证明存在包静态引用缺口，不能直接断言工具执行失败或已有生成器的责任。清单声明的 `.kimi-code/skills` 还因目录不存在显示来源失败。

没有修改这些目录、运行生成器或技能脚本。本轮不把镜像扫描结果混入默认跳过镜像的 649 个原源候选统计；其它副本的镜像尚未逐一扫描。
