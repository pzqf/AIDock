# 安全审计查询与验收台账 · v0.64.0-dev

控制台增加“安全审计”，查询当前绑定的来源证据、安装登记、项目权限、运行时核验和 MCP 会话五条独立审计链。CLI 为 `aidock audit [--category origin|install|permission|runtime|session] [--search 文本] [--page 页码] <绑定参数> --json`，认证 API 为 `GET /api/audit`，三者共用 Engine 报告。

## 完整性和展示

复用各 store 的排他锁、待恢复检查、原有链验证及本机事务锚点；不建立新的审计权威。损坏类别返回 FAIL、安全错误码和未知数量，不返回其部分事件或链尾。其它已核对类别继续显示；分类和搜索不会跳过坏链检查。源文件损坏不隐藏本机审计。

每页 50 条，按时间 instant 倒序、类别和链内序号稳定排序。显示事件 ID、时间、动作、主体、账户、关联尝试、方法/工具/请求 ID 及记录摘要；不输出用途、风险理由、权限值、manifest、工具参数/返回正文或密钥。安装的低信任显式放行标为 RISK_ACCEPTED；独立非隔离确认单独标记。文本按字面展示。

source 范围绑定项目、作用域和源目录；copy 范围另含副本。无 copy 的会话类别为 NOT_APPLICABLE。API 成功读取时保留报告，即使某链失败；CLI 对失败链退出 5。底层 Capture 可创建 Local 观察缓存和锁，项目源、产物及审计权威字节不变。

页面提供分类、搜索、分页和摘要详情。搜索草稿改变即隐藏旧结果并禁止沿用旧页；源刷新使报告失效，迟到响应不能恢复旧结果。完整性详情默认折叠，失败时自动展开。初始化完成前入口禁用。

## 存证边界

当前只有本机链和事务核对，没有外部可信锚点；同用户整体重写或删除不在保证范围内。分段封存、归档尚未实现。凭据审计和源/原生文件/副本回退历史仍在各自页面，本报告不能代表全部产品事件。查询不启动程序、不打开凭据库、不授权、不恢复或改写历史。

## 验收

专用测试项目中通过真实 Node MCP 客户端完成握手、Public 查询、越界拒绝、撤销和 EOF 清理；补充 26 组真实授权/撤销，累计 88 条事件。CLI/API 核对五链、风险放行、50 条分页、精确 ID 搜索、copy 隔离、原绑定、认证与方法限制。损坏权限链退出 5，不泄露部分事件或原值；其它类别仍可查。注入后恢复原字节，源、产物与审计权威树未被查询改变。

内置浏览器核对安装风险确认、55 条权限历史第二页、搜索草稿失效及精确定位；坏链自动展开并显示未知数量，恢复夹具原字节后刷新通过。390/1280 宽度无页面横向溢出，warn/error 为 0。截图为 browser-install.jpg、browser-damaged.jpg、browser-release.jpg 和 browser-narrow.jpg。

10 个受影响包完整回归与完整竞态通过；29 组前端状态及 29 个 JS 语法检查、go vet、Windows 构建和 Linux 交叉构建通过，Linux 未运行。首次两个测试夹具断言有误（缺 Local 父目录、既有 API 错误 HTTP 契约），修正后重跑通过，失败日志保留。CI 改为自动发现全部前端脚本和状态测试，避免遗漏新增页面。
