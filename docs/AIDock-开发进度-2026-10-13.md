## 真实场景结果

明确清单 `examples/dragon-workspaces.scan.yaml` 描述 15 个 project/scope/copy 选择、45 个源/镜像目录声明。三个项目 UUID 是只读选择的临时标签，不是持久登记或已确认副本身份；同名资产不因此自动绑定。

- 工作区技能：每 copy 1 个，共 5 个。
- 服务端技能：work/work2/work3/work4 各 72 个，work5 为 71 个，共 359 个。
- 客户端技能：每 copy 57 个，共 285 个。
- 合计 **649 个候选**：614 个通过有限静态检查，35 个有跨技能/项目外引用警告。无静态 FAIL，退出码 0 只表示盘点完成。
- 镜像默认 SKIP。角色依据清单声明，未验证生成关系；配置生成、工具发现、新会话加载、实际能力均未判 PASS。

初版正则曾把示例代码里的 Markdown 链接误判为缺文件，已改为 Markdown AST 并加入负向回归；不能把旧的 15 个误报当作项目配置缺陷。35 个警告需要在正式纳管时明确 dependencies/project_files，不直接断言引用已失效。

本轮没有执行已有生成器、Git/SVN 更新/提交/还原、技能脚本或 MCP 插件。扫描器只读取授权源，测试验证完整包字节不变；没有向实际工作区写入配置。
