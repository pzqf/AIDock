认证 API 为 POST /api/snapshots/replay/prepare（同请求）和 POST /api/snapshots/replay/prepared（id）。沿用严格 JSON、CSRF/Origin、项目绑定、长度限制和工作锁。

界面：时间线 → 读取应用快照 → 审查回放候选授权 → 完整回放候选检查。先静态编译显示工具集合，再单独确认隔离发现和规则来源；取消勾选不运行。可复制检查 UUID，重新打开后输入并重读。重读只复核，不自动运行进程。过期后不展示旧差异或把历史通过作为当前通过。

## 编译、隐私与证据边界

- Source.WithReplayExport 用冻结投影和原 Local 层重新解析、选择完整包。保留 inherited/override/external 的只读来源与精确修订语义，不转成 owned；不继承今天的全局默认来替换历史输入。
- 候选摘要新增绑定历史/当前权威根、外部桥路径和观察摘要；桥登记变化使旧候选过期。新版本不会复用旧格式的待确认候选摘要，已提交恢复历史和独立回退仍保留。
- 使用正常原生编译器的所有权、路径重叠、重名/漂移、手写规则和优先级检查。只在内部把 MCP 交给现有完整候选连接编译器；MCP 不完整时整体保持 NEEDS_ATTENTION，其它 Profile 未适配条件继续阻断。
- 当前 source/Local、全部目标、规则优先级、适配器与工具程序、授权、最新运行时、完整产物及 AIDock 程序内容参与重读复核。探测后重新编译并核对候选，过期不会自动重新探测。
- 手写规则也可能含私有内容，因此检查使用受限的 native-mcp-private 编译资产区。原生前后字节、完整内部 Plan 及规则正文不进入普通 Source blob 桶或公共报告。原生恢复资产统一转存至原 native transaction blob 桶；公开只含身份、哈希、文件差异和核验元数据。
- 程序路径和当前 home 在任何探测之前验证。静态阻断的整体候选不会启动部分工具。明确探测仅在空配置临时项目运行固定版本发现/规则来源协议，不运行技能脚本、MCP 入口或模型请求。
- L1、隔离发现 L2、规则来源和实际技能会话 L3/L4 分开；CHECKED 不证明实际项目新会话、模型遵从或 OS 网络隔离，也不开放共同应用。
