# AIDock 验收台账

更新：2026-10-18，v0.83.0-dev。Goal 为 active，阶段 1 总验收未完成。完整条件见 [开发计划](./AIDock-开发计划.md)；本台账使用相同的 59 个稳定 ID，机器版见 [JSON](./AIDock-验收台账.json)。

“已验收”只表示对应整条条件；“待联合验收”表示已有独立实施证据，仍需按整条条件复核；“部分实现”有明确功能缺口；“待外部验收”需要外部运行证据；“未开始”保留后续工作。不能把这些状态换算成产品完成百分比。历史实施记录不代替当前完整联合验收。

当前已具备项目/完整技能包、继承、分层 Profile、两工具应用、诊断、独立 MCP 授权与受管 Public 查询、源与应用快照、回放、owned 技能/规则和声明共享插件字段的正式副本事务。v0.81 接通 MCP 定义/精确锁与逐目标独立准备；v0.82 接通完整候选编译、全部启用 MCP 门槛、明确工具发现/规则来源及过期重读。v0.83 接通完整候选核心真实共同事务与固定应用视图，正式完整批次发布/共同恢复入口、明确删除、外部生成器、技能 L3/L4、隔离、依赖恢复和审计分段仍未完成。阶段 1E 总验收及阶段 2–5 按原计划继续。历史证据见开发进度和各版实施记录。
