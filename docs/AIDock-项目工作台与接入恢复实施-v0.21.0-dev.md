## 用户流程

运行 `aidock config --home <独立数据根>` 可直接进入项目工作台。在管理界面输入项目名称和已有项目目录，选择新建配置或打开已有配置，预览写入范围后确认。新建只初始化 `.aidock/project.yaml`、`skills.yaml`、`profile.yaml`，已有非空配置不会被覆盖；打开保留已有项目和作用域身份。绝对目录会先规范化，确认窗口显示最终路径。

项目列表与跨副本页面共用本机副本登记，不维护第二份项目路径表。复制来的同项目配置接入后成为同一作用域下的另一个副本。项目名称用于导航，项目、作用域与副本身份仍由后端核对。

打开项目后沿用技能创建、导入、编辑、启停、检查、工具文件安装与源回退流程。每个标签页在请求头携带固定入口身份，服务端派生请求专属 Engine；迟到请求不会因另一标签页切项目而改变目录。切换前检查当前页面所有文件、治理和表单草稿；有草稿时允许留在当前项目或新标签页打开，草稿保留在原页面。

失效或未登记的项目链接返回项目工作台并显示原因，不读取默认项目的技能源。登记失败时项目接入历史仍可读，从历史预览恢复范围后恢复。源损坏不阻止解析已登记身份，后续源读写继续执行原有校验。

## 持久事务与边界

创建源与保存副本登记使用同一个多目录事务：完整预览和摘要确认、逐根锁与持久标记、写前备份、确认前重新观察全部内容。预览只观察并把备份写到 Local，不在项目中创建锁文件；确认时才获取原有全部目录锁。源或登记变化会阻止旧计划；重复确认已提交计划不重复写入。中断后恢复两根，外部编辑冲突保留并允许解决后重试。提交已保存但清理标记时中断，只收口标记，保留已提交内容。

项目接入计划在本机 Local Root 保存。CLI 等价入口为 `project list/add/confirm/history/recover`，`add --file` 只预览；`--binding` 可替代手工源绑定。显式 `--home` 的项目工作台、项目管理与入口绑定统一使用其 `local` 子目录，与显式源管理保持一致。

本次不删除项目文件、备份或副本登记。项目移除仍为预留；跨项目库关联和外部桥接的持久界面配置继续开发。切回启动时同一明确绑定会保留原库/桥接上下文，切到其他项目不会继承这些路径。新建作用域默认 `workspace`，打开已有配置保留其作用域。
