# 源时间线检索与分页验收

版本：v0.49.0-dev。状态：源时间线检索、分页和按记录回退已验收；完整 Goal 与阶段 1 继续推进。

## 用户流程

“时间线与回退”只展示当前项目的技能源记录，可搜索动作、记录 ID 和时间，叠加技能、Profile/规则、MCP 定义/锁、源回退/撤销、其它动作及保存/恢复状态筛选。每页 20 条，显示匹配总数、页数和上一页/下一页边界。筛选重置页码，重读后记录减少会自动收敛到有效页。

回退继续绑定所选稳定记录 ID，确认框同时显示原动作、时间和 ID。ID 搜索只匹配记录自身，不把回退动作中引用它的其它记录当成同一记录；完整引用仍保留在事务详情。改变筛选或翻页不替换已经生成的候选，也不保存源或丢弃技能草稿。回退影响整个项目源状态；本机 Profile 与工具文件仍使用各自的恢复记录。待恢复时可只读查找记录，新的回退和源保存继续阻断。
