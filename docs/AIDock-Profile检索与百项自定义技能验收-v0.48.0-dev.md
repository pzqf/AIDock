# Profile 检索与百项自定义技能验收

版本：v0.48.0-dev。状态：Profile 检索、明确范围的批量操作及百项自定义技能功能样例已验收。阶段 1 与完整 Goal 继续推进。

## 用户流程

“Profile 与规则”的技能组合支持按展示名、原生名、说明、稳定 ID、固定修订搜索，多个关键词共同匹配；可叠加技能来源和本层草稿的明确启用、明确停用、继承上层筛选。同展示名的独立身份分别列出，不折叠。

匹配数量及三态总量始终来自当前草稿。“启用筛选项”“停用筛选项”“筛选项继承上层”仅处理点击时匹配的技能；零匹配时禁用。原有全部启用/停用放入明确标注“包含隐藏项”的全部操作，保留全部语义。

所有操作先进入共享或本机草稿，继续使用现有预览、摘要绑定、明确保存和完整回退点。继承只解除本层开关，保留固定版本、包内容和其它 Profile 字段。共享和本机预览均逐项列出三态前后变化，包含停用转继承。

搜索只刷新技能列表，保留规则输入、其它编辑焦点、未保存修改及已有预览。取消、关闭重开、外部变化和过期确认沿用草稿保护。已保存有效配置和候选有效配置按需展开，避免百项报告挡住日常编辑。

## 验证

证据目录：.artifacts/experience-profile-scale-v048/。独立夹具通过正常 CLI 创建两个登记项目，每项目 100 个 owned 自定义技能、10 个全局继承和 1 个外部批准包，共 212 个独立身份、222 项项目选择；每项目 55 个导入包包含二进制和空目录。

内置浏览器分别验证两项目的 100 个自定义技能筛选、同名独立资产、三种来源和三态组合。项目 A 的十项共享选择完成预览、取消、关闭重开、确认保存及整批回退/撤销；两项本机覆盖完成独立保存、回退、撤销并恢复原配置。项目 B 的两项草稿预览取消后放弃，文件未改变。列表保留固定包版本、开关来源和两工具 L1–L4 展示，未验证项没有变为通过。

独立脚本核对全部 222 项完整包清单及原始导入、外部源和全局库。共享回退后项目 A 全目录树与操作前相同；撤销回退后只有 .aidock/profile.yaml 是本次明确保存的变化，项目 B 全树保持原样。两项目静态检查均 PASS；二进制读取只返回元数据。390×844 页面与弹窗无横向溢出，最终页面 warn/error 为 0。

24 组前端回归通过，新增两项目百项功能样例覆盖筛选交集、匹配范围、全部语义、固定版本、规则保持、共享/本机隔离、草稿、取消、过期、忙碌状态和逐项三态预览。24 个 JS 语法、58 项 Demo、gofmt、vet、Windows 构建及 Linux 交叉构建通过；Linux 未运行。受影响 console、cli、source 三包关闭缓存竞态为 283 PASS / 1 SKIP / 0 FAIL，退出 0，不代表其它包本次全部重新验收。
